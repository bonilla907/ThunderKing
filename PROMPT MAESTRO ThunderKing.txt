# PROMPT MAESTRO — SISTEMA DE GESTIÓN DE PEDIDOS PARA EMPRESA DE SERIGRAFÍA

Quiero que desarrolles un sistema web completo para una empresa dedicada a servicios de **serigrafía, bordado, impresión de lonas, personalización de prendas y trabajos relacionados**.

El sistema deberá construirse por **9 etapas claramente separadas**.

## REGLA PRINCIPAL DE DESARROLLO

Debes conocer desde el inicio toda la arquitectura y alcance descritos en este prompt, pero **NO debes implementar todas las etapas de golpe**.

Debes trabajar exclusivamente sobre la etapa que yo indique.

Cuando te solicite una etapa:

1. Analiza primero la estructura existente del proyecto.
2. Reutiliza componentes y lógica existente cuando corresponda.
3. No elimines funcionalidades anteriores que ya estén funcionando.
4. No avances a etapas posteriores.
5. No agregues módulos futuros salvo la estructura mínima necesaria para evitar problemas de arquitectura.
6. Mantén siempre compatibilidad con las etapas siguientes.
7. Antes de terminar cada etapa, revisa imports, rutas, nombres de variables, estructura de Firebase y posibles errores.
8. El código debe quedar funcional, limpio y listo para probar.
9. No uses datos falsos si ya existe conexión con Firebase.
10. Si falta algún dato externo imprescindible, deja claramente identificado dónde debe colocarse, sin inventarlo.

# 16. REGLA FINANCIERA

La regla principal deberá ser siempre:

```text

```

Donde:

```text
TotalPagado = suma de todos los registros de Pagos
```

No confiar únicamente en valores calculados por React.

Cuando sea necesario, validar y recalcular desde backend.

No permitir valores negativos o inconsistentes salvo que una regla futura explícitamente lo autorice.
